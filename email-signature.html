Email signature

Table-based HTML with web-safe fonts and a hosted raster logo, so it survives Gmail, Outlook and Apple Mail. Two versions.

Deploy the site before you send with this. The copied signatures point at vpe-mark-email.png (full) and vpe-glyph-email.png (compact) under https://www.vpathingenterprisellc.site/assets/brand/. Neither exists yet — assets/brand/ is new and unpublished. Until you deploy, the logo will be a broken image in sent mail. The previews below use local files, so they render here regardless.

The www is deliberate: the bare domain answers 308 and redirects to www, and some mail clients' image proxies will not follow a redirect. Pointing straight at www avoids the hop.

Installing it

“Copy signature” puts the formatted version on your clipboard — paste it straight in. Use “Copy HTML source” only where a client asks for raw HTML.

Gmail

  1. Settings (gear) → See all settings → General tab.
  2. Scroll to Signature → Create new, and name it.
  3. Click into the signature box and paste with Ctrl+V. Do not use “paste as plain text” — it strips the layout.
  4. Set the “For new emails use” and “On reply/forward use” dropdowns.
  5. Save Changes at the bottom. Gmail does not save until you do.

Outlook (web / new Outlook)

  1. Settings (gear) → Mail → Compose and reply.
  2. Paste into the signature editor and save.

Apple Mail

  1. Mail → Settings → Signatures.
  2. Create a signature, then untick Always match my default message font — leaving it on flattens the formatting.
  3. Paste into the signature pane.
If the logo does not appear: most clients block remote images until the recipient allows them — that is normal and not a fault in the signature. The alt text keeps the company name readable meanwhile. But if it never loads for you either, check that /assets/brand/vpe-mark-email.png is actually live on the deployed site.
